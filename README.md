# Schuler Auktionen – prototípus

Vanilla HTML/CSS/JS, build nélkül. Nyisd meg az `index.html`-t (vagy GitHub Pages-en publikáld).

- `index.html` főoldal, `auction.html` aukció, `category.html` Antique Weaponry, `lot.html` tétel, `appraisal.html` Appraisal days
- `styles.css`, `app.js` közös stílus és animációk (menü, tabok, scroll-reveal, parallax)
- `assets/` felhasznált képek

A tartalom nélküli linkek és gombok szándékosan nem kattinthatók.
